Vesper (Lookiyam) is a quiet twilight theme. Violet-black toolbars and a darker tab bar carry soft grey-white text, and a twilight-violet highlight marks focus and selection. The Start Page shows the Vesper mark: the evening star above a sun half set behind a line of violet light.

Part of the Lookiyam themes, made to match the Vesper theme for the Omarchy Linux desktop. All backgrounds, from the evening star to the still dusk lake, and the build script are at https://github.com/lookiyam-94/vivaldi-lookiyam-themes
